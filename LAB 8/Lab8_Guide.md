# Lab 8 - Repetition and Number-Series Programs using `While` and `Do While` loops

## What this lab is about

This lab uses `while` and `do while` loops to repeat instructions and solve number-based problems. The programs practise:

- `while` and `do while` loops
- Counters and accumulators
- Odd and even numbers
- Divisibility using the remainder operator
- Number series and sums
- Repeated addition and subtraction
- Square roots using the math library

---

## 1. The `while` loop

A `while` loop repeats a block of code as long as its condition is true.

### Syntax

```c
while (condition)
{
    // statements to repeat
}
```

### Example: print 1 to 10

```c
#include <stdio.h>

int main()
{
    int number = 1;

    while (number <= 10)
    {
        printf("%d ", number);
        number++;
    }

    return 0;
}
```

### How it works

```text
Start number at 1
       |
       v
Is number <= 10?
   |             |
  Yes            No
   |             |
Print number   Stop
   |
Increase number
   |
Repeat
```

The counter must be changed inside the loop. If it is not changed, the condition may remain true forever and cause an infinite loop.

---

## 2. The `do while` loop

A `do while` loop executes its body first and checks the condition afterwards. Therefore, its body runs at least once.

### Syntax

```c
do
{
    // statements to repeat
} while (condition);
```

Notice the semicolon after the condition.

### Difference between `while` and `do while`

| Loop | Condition is checked | Minimum executions |
| :--- | :--- | :---: |
| `while` | Before the loop body | 0 |
| `do while` | After the loop body | 1 |

When a `do while` loop should not run for invalid input, check the input with an `if` statement first.

## 3. Counters and accumulators

A **counter** records how many times something happens. It is commonly increased by `1`.

```c
count++;
```

An **accumulator** stores a running result, such as a sum.

```c
sum = sum + number;
```

The accumulator should normally be initialized before the loop:

```c
int sum = 0;
```

### Example: sum from 1 to n

```c
int number = 1;
int sum = 0;

while (number <= n)
{
    sum += number;
    number++;
}
```

The short form `sum += number` means the same as `sum = sum + number`.

## 4. Checking odd, even, and divisible numbers

The remainder operator `%` gives the remainder after integer division.

```c
number % 2 == 0
```

This condition is true when `number` is even.

```c
number % 2 != 0
```

This condition is true when `number` is odd.

To check divisibility by another number:

```c
number % divisor == 0
```

A remainder of zero means that the number is exactly divisible.

### Example: divisible by 7 but not by 5

```c
if (number % 7 == 0 && number % 5 != 0)
{
    printf("%d ", number);
}
```

The `&&` operator requires both conditions to be true.

## 5. Generating a number series

A series can be generated by updating the current term during each loop iteration.

For the series `1, 4, 7, 10, ...`, the difference between consecutive terms is `3`:

```c
number += 3;
```

A separate counter is useful when the question asks for a fixed number of terms, such as the first 50 terms.

```c
int term = 1;
int count = 1;

while (count <= 50)
{
    printf("%d ", term);
    term += 3;
    count++;
}
```

## 6. Squares and square roots

The expression below calculates the square of an integer:

```c
square = number * number;
```

To calculate a square root, include `<math.h>` and use `sqrt()`:

```c
#include <math.h>

printf("%.2f", sqrt(number));
```

`sqrt()` returns a floating-point value, so `%f` or a precision format such as `%.2f` should be used when printing it.

When compiling with GCC, the math library may need to be linked:

```text
gcc B_1.c -o B_1 -lm
```

## 7. Division without `/` and `%`

Integer division can be simulated with repeated subtraction.

```text
Set quotient to 0
Set remainder to the dividend
While remainder >= divisor:
    subtract divisor from remainder
    increase quotient
```

At the end:

- `quotient` contains the number of successful subtractions.
- `remainder` is smaller than the divisor.

The divisor must not be zero. For the lab exercise, enter the bigger number first and a positive smaller number second.

## 8. Multiplication without `*`

Multiplication can be simulated with repeated addition.

For example, `4 * 3` means adding `4` three times:

```text
product = 0
repeat 3 times:
    product = product + 4
```

In C, a counter controls the number of additions:

```c
int count = 0;

while (count < second)
{
    product += first;
    count++;
}
```

If negative numbers are accepted, handle their signs separately and perform repeated addition using positive values.

## 9. Important mathematical note for C_1.c

The square of an integer can end only in one of these digits:

```text
0, 1, 4, 5, 6, 9
```

It can never end in `3`. Therefore, there are no integers whose square has last digit `3`, and the requested first 10 integers do not exist.

For this reason, `C_1.c` prints an explanatory message instead of attempting to calculate a sum or average.

This is a useful example of checking whether a requested set of values is mathematically possible before writing an endless search loop.

## Common mistakes

- Forgetting to initialize a counter or sum.
- Forgetting to update the counter inside a loop.
- Using `=` instead of `==` in a condition.
- Forgetting the semicolon after a `do while` condition.
- Using `/` when the exercise requires repeated subtraction.
- Using `%` when the exercise specifically forbids it.
- Dividing by zero.
- Using `%f` incorrectly when printing the result of `sqrt()`.
- Not checking the input before using a `do while` loop.
